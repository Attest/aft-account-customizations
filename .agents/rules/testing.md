# Testing

## Current State

This repository has no automated tests. All validation happens at apply time in the AFT CodePipeline.

## Recommended Local Checks

Before committing changes, run:

```bash
# Format check
terraform fmt -check -recursive

# Syntax validation (per account folder)
cd <account>/terraform
terraform init -backend=false
terraform validate
```
